# حساباتي — برنامج محاسبة للمحل على الآيفون

برنامج محاسبة بسيط باللغة العربية وبالدينار العراقي (د.ع). يعمل على الآيفون مثل أي تطبيق، وبدون إنترنت بعد أول فتح.

## المميزات
- **البيع**: بيع نقدي وبيع آجل (دين) مع دفعة مقدمة، خصم، طباعة الفاتورة أو إرسالها بالواتساب.
- **الشراء**: فواتير شراء من الموردين (نقدي أو آجل)، تضيف الكميات للمخزن وتحدّث سعر الكلفة تلقائياً.
- **المخزن**: المنتجات بالعدد/الوحدة، سعر الشراء والبيع، تنبيه عند قرب النفاد، قيمة المخزن.
- **المصاريف**: إيجار، كهرباء، مولدة، نقل… مع تصنيف وتقرير شهري.
- **العملاء والموردون**: الديون، قبض/تسديد الدفعات، كشف حساب يمكن إرساله للزبون.
- **الموظفون والرواتب**: راتب شهري، سلف خلال الشهر، صرف الراتب نهاية الشهر
  (الراتب + المكافأة − الخصم − السلف = الصافي)، قسيمة راتب، و«صرف رواتب الجميع» بضغطة.
- **التقارير** (اليوم / الأسبوع / الشهر / السنة / فترة محددة):
  الأرباح، المبيعات، المصاريف، العملاء، المخزن، الرواتب — مع إمكانية الطباعة.
- **رصيد الصندوق**: النقد المتوفر محسوب تلقائياً من كل الحركات.
- **نسخ احتياطي واسترجاع** للبيانات.

## طريقة التنصيب على الآيفون
1. ارفع البرنامج على أي استضافة (مثلاً GitHub Pages: من إعدادات المستودع ← Pages ← اختر الفرع ثم Save).
2. افتح الرابط من متصفح **Safari** على الآيفون.
3. اضغط زر **المشاركة** (المربع والسهم) ← **إضافة إلى الشاشة الرئيسية**.
4. ستظهر أيقونة «حساباتي» على الشاشة، افتحه منها مثل أي تطبيق.

## ملاحظات مهمة
- البيانات محفوظة **على الجهاز نفسه** فقط. خذ **نسخة احتياطية** أسبوعياً من «المزيد ← الإعدادات» واحفظها في الملفات أو أرسلها لنفسك.
- لتجربة البرنامج: الإعدادات ← «تحميل بيانات تجريبية» (يظهر فقط عندما يكون البرنامج فارغاً).

## الملفات
- `index.html` — الصفحة الرئيسية
- `js/app.js` — منطق البرنامج كاملاً
- `css/style.css` — التصميم
- `sw.js` و `manifest.webmanifest` — تشغيل بدون إنترنت والتنصيب كتطبيق
